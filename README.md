## Use it

In a React 19 project, copy a component from [components/](https://github.com/brio-ui/brio-ui/tree/main/components) and install its dependency:

```bash
npm install motion
```

```tsx
import { Faq } from './components/faq'

<Faq items={[{ q: 'Can I change this?', a: 'Yes. The source is yours.' }]} />
```

TypeScript source. Styles included. No Tailwind or provider required.

Early release. These 3 components are [MIT licensed](https://github.com/brio-ui/brio-ui/blob/main/LICENSE). Website docs and registry installs are rolling out; use the files here today.
